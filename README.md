# 듀얼넘버 라이트 (갤럭시용)

듀얼번호로 걸려온 전화를 구분해 알려주고, 듀얼번호로 바로 회신하게 도와주는 안드로이드 앱입니다.

> 1.0 버전은 문자·통화기록 권한 때문에 갤럭시에서 **피싱 의심 앱으로 설치가 차단**되어,
> 위험 권한을 모두 뺀 **라이트 버전(2.0)** 으로 바꿨습니다.

## 다운로드
**최신 APK:** [Releases](https://github.com/saytu1/dualcall/releases/latest) → `DualNumber-숫자.apk`

## 원리
- 상대가 **내 듀얼번호**로 전화하면 상대 번호 끝에 `#`(또는 `*`)이 붙어 들어옵니다.
- 앱이 **"발신자 확인 및 스팸 앱"** 역할로 걸려온 번호를 확인해, `#`이 있으면 **듀얼**로 기록하고 알림을 띄웁니다.
- 회신할 때 상대 번호 뒤에 `#`을 붙여 전화 앱·메시지 앱을 열어주면, 상대에게 **내 듀얼번호**가 표시됩니다.

## 주요 기능
- 듀얼번호로 전화가 오면 **"듀얼 · 상대" 알림** (알림에서 바로 "듀얼로 문자/전화")
- 상대별 통화 기록 (전체 / 기본 / 듀얼 탭, 검색)
- 대화 화면: "듀얼로 전화" · "듀얼로 문자", 반대 번호로 보내기, 이름 붙이기, **수신 원본 번호 표시**(# 전달 확인용)
- 새로 보내기: 번호 입력 또는 **연락처에서 선택** → 기본/듀얼 선택 발신
- 판별 테스트, 다크 모드

## 권한
| 사용 | 사용 안 함 |
|---|---|
| 알림 | 문자, 통화기록, 연락처, 전화 걸기 |

수신 감지는 권한이 아니라 사용자가 직접 지정하는 **"발신자 확인 및 스팸 앱" 역할**로 동작합니다. 기록은 폰 안에만 저장됩니다.

## 설치
1. 폰에서 APK 다운로드 후 열기 → "출처를 알 수 없는 앱" 허용
2. 설치가 막히면: 설정 → 보안 및 개인정보 보호 → **자동 차단** 끄기 (설치 후 다시 켜도 됨)
3. 앱 실행 → 내 번호 입력 → **시작하기**
4. "듀얼넘버를 발신자 확인 및 스팸 앱으로 설정할까요?" → **기본으로 설정**
5. 알림 허용

직접 설정: 설정 → 애플리케이션 → **기본 앱 선택** → **발신자 확인 및 스팸 앱** → 듀얼넘버
(후후·T전화 같은 스팸 차단 앱이 지정돼 있었다면 듀얼넘버로 바뀝니다)

## 첫 테스트 체크리스트
- [ ] 다른 폰으로 **내 듀얼번호**에 전화 → "듀얼" 알림이 뜨는지
- [ ] 앱 대화 화면의 **수신 원본**에 `#`이 붙어 있는지
- [ ] 기본번호로 온 전화는 "기본"으로 기록되는지
- [ ] "듀얼로 전화" → 다이얼러에 `번호#` 입력 → 통화 → 상대에게 듀얼번호가 뜨는지
- [ ] "듀얼로 문자" → 메시지 앱에 `번호#` 입력 → 상대에게 듀얼번호로 도착하는지

## 알아둘 점
- **설치·설정 이후** 걸려온 전화부터 기록됩니다. 과거 통화기록과 문자 수신 구분은 지원하지 않습니다.
- 안드로이드 정책상 **연락처에 그대로 저장된 번호**는 앱에 전달되지 않을 수 있습니다. 듀얼번호로 온 전화는 끝에 `#`이 붙어 연락처와 달라서 보통 전달됩니다.
- 빌드마다 서명 키가 달라서, 새 버전 설치가 안 되면 기존 앱을 지우고 설치하세요.
