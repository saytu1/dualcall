# 듀얼넘버 (갤럭시용)

기본번호와 듀얼번호로 주고받은 전화·문자를 구분해서 보여주고, 듀얼번호로 바로 회신하는 안드로이드 앱입니다.

## 원리
- 상대가 **내 듀얼번호**로 연락하면 내 폰 기록에 상대 번호가 `01099990000#` 처럼 끝에 기호가 붙어 남습니다.
- 앱은 끝의 `#`(또는 `*`)를 보고 **듀얼**, 없으면 **기본**으로 분류합니다.
- 회신할 때 상대 번호 뒤에 `#`을 붙여 걸거나 문자를 보내면, 상대에게 **내 듀얼번호**가 표시됩니다.

## 주요 기능
- 통화기록 + 문자를 상대별로 묶어서 표시 (전체 / 기본 / 듀얼 탭, 전화 / 문자 필터, 검색)
- 대화 화면: 시간순 기록, "듀얼로 전화" · "듀얼로 문자" 버튼, 반대 번호로 보내기
- 새로 보내기: 연락처나 번호를 골라 기본/듀얼 선택 발신
- 연락처에 `#` 붙여 저장한 번호도 이름으로 표시
- 다크 모드 지원

## APK 만들기 (GitHub Actions, PC 설치 불필요)
1. GitHub에서 새 저장소 생성 (Private 권장)
2. 이 폴더 전체를 저장소에 업로드 (`.github` 폴더 포함 필수)
   - 웹에서: 저장소 → **Add file → Upload files** → 폴더 내용 드래그
3. 업로드하면 자동으로 빌드 시작 → **Actions** 탭에서 진행 확인 (약 5~8분)
4. 완료 후 저장소 오른쪽 **Releases** → `DualNumber-숫자.apk` 다운로드

## 갤럭시에 설치
1. 폰에서 APK 파일 열기 → "출처를 알 수 없는 앱" 허용 (브라우저 또는 내 파일 앱)
2. 설치 후 앱 실행 → 내 번호 등록 → **시작하기** → 권한 모두 허용
3. 권한 허용이 막히면 ("제한된 설정"):
   설정 → 애플리케이션 → 듀얼넘버 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 권한에서 직접 켜기

## 첫 테스트 체크리스트
- [ ] 다른 폰으로 **내 듀얼번호**에 전화 → 앱에서 "듀얼"로 분류되는지
- [ ] 다른 폰으로 **내 듀얼번호**에 문자 → 앱에서 "듀얼"로 분류되는지 (통신사에 따라 다를 수 있음)
- [ ] 기본번호로 온 전화·문자는 "기본"으로 분류되는지
- [ ] "듀얼로 전화" → 상대 폰에 내 듀얼번호가 뜨는지
- [ ] "듀얼로 문자" → 삼성 메시지 앱에 `번호#`이 들어가고, 상대에게 듀얼번호로 도착하는지

## 알아둘 점
- 빌드할 때마다 서명 키가 새로 만들어지므로, 새 버전 설치 시 "앱 설치 안 됨"이 뜨면 기존 앱을 지우고 설치하세요.
- MMS(사진 문자)는 1차 버전에서 제외했습니다.
- 기록은 폰 안에서만 읽고, 외부로 전송하지 않습니다.
